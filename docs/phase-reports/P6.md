## 1. What Was Built

### 1.1 Gap Rules Engine (`packages/rules/src/c2b_rules/gap.py`)
- **Universal Gap Rules (`docs/04 §7.3`)**:
  - `R-GAP-001`: Rating label (`label.rating`) suggested for physical products.
  - `R-GAP-002`: User manual / quick start guide (`documentation.manual`) suggested for end products.
  - `R-GAP-003`: Shipper carton (`packaging.carton`, level `mbom`) suggested for packaged finished goods.
- **Class-Triggered & Process-Triggered Gap Rules**:
  - `R-GAP-021`: Solder wire (`consumable.solder`, level `mbom`) suggested when PCB or soldering process hints appear in description/notes. Proposes formula estimate based on joints.
  - `R-GAP-004`: Fasteners / hose clamps (`fluid.clamp`) triggered by fluid connections.
  - `R-GAP-030`: Transport labels (`label.transport`) triggered by battery cells (`electrical.battery.li_ion`).
- **Archetype Skeletons & Fallback**:
  - Archetype skeleton suggestions for known archetypes (`ceiling_fan`, `power_bank`).
  - Fallback ladder L4 handles unknown product archetypes (e.g. B6 handheld controller), producing low-confidence gap candidates.
- **Permanent Suggestion Rejection Suppression**:
  - When a user rejects a suggestion, a composite key (`{rule}:{class}`) and suggestion ID are saved in `draft.rejected_suggestion_keys`.
  - Re-evaluating gap rules skips any previously rejected rule/class, ensuring rejected items are never re-suggested.

### 1.2 MBOM Derivation Engine (`packages/rules/src/c2b_rules/mbom.py`, `docs/04 §10`)
- **Structure Transformations**:
  - **Collapsed Phantoms**: Modelling assembly groups (`assembly.phantom`, e.g. `FASTENERS_GRP`) are collapsed out of the MBOM; their leaf components are promoted to the phantom's parent with sequentially incremented find numbers.
  - **Purchased Assemblies**: Assemblies marked `buy_as_assembly=True` (e.g. `LightKit`) are treated as a single line item; their internal parts are omitted from the MBOM.
  - **Subassembly Preservation**: Manufactured subassemblies (e.g. `BladeAssy`) retain parent-child hierarchy in MBOM.
  - **Sequential Find Numbers**: Find numbers are assigned at intervals of 10 (`find_no=10, 20, 30...`), resetting per subassembly parent.
  - **Traceability (`ebom_refs`)**: Every MBOM line preserves explicit reference back to the original EBOM line ID (`L-0001`...).
  - **Strict Acceptance Gate**: Unreviewed suggestions (`review="suggested"`) are never added to the MBOM (satisfying Non-negotiable Rule 5: *"Nothing is added to the BoM before a suggestion is accepted"*). Only suggestions with `review="accepted"` are converted into MBOM items.

### 1.3 Make/Buy Recommender (`packages/rules/src/c2b_rules/makebuy.py`)
- **Priority Ladder**:
  1. Explicit user override: `source="user"`, confidence 1.0 (never overwritten).
  2. Standard catalogue parts (fasteners, bearings, O-rings, standard tables): classified as `buy` (confidence 0.95, rule `R-MKB-001`).
  3. Custom single parts: classified as `supplier_made` (made to drawing by vendor; rule `R-MKB-002`).
  4. Top-level assemblies & in-house subassemblies: classified as `make` (rule `R-MKB-ASM`).
- **Annual Volume Bands (`R-MKB-VOL`)**:
  - Volume hints extracted from job description or details (e.g. "annual volume 50000").
  - Injected notes advising tooling strategy (e.g. low-volume soft tooling vs multi-cavity hardened steel injection mould).

### 1.4 Part Numbering Engine (`packages/rules/src/c2b_rules/numbering.py`)
- **Profile-Driven Sequential Numbering**:
  - Preserves existing part numbers from user BoM or CAD metadata.
  - Generates standardized designation keys for standard parts (e.g. `FAS-ISO4762-M4X12`).
  - Generates formatted numbers `{prefix}-{seq:05d}` using taxonomy prefixes from the active organization profile (e.g. `SHM-00010`, `MLD-00020`, `MCH-00030`).

### 1.5 Validation Engine & Approval Endpoint (`packages/rules/src/c2b_rules/validator.py`, `apps/api/src/c2b_api/jobs.py`)
- **Blocking Criteria (Prevents Release Approval)**:
  - `unresolved_question`: Open blocking questions requiring user input (`R-VAL-001`).
  - `open_suggestion`: Open unreviewed suggestions that must be accepted or rejected (`R-VAL-002`).
  - `invalid_quantity`: Non-positive or null quantity per parent (`R-VAL-QTY`).
  - `unknown_uom`: Unrecognized unit of measure (`R-VAL-UOM`).
  - `circular_dependency`: Assembly cycle detected in parent-child hierarchy (`R-VAL-CYC`).
  - `duplicate_part_number_conflict`: Reused part number with conflicting description (`R-VAL-DPN`).
  - `unclassified_part`: Unclassified component class (`R-VAL-CLS`).
- **Non-blocking Warnings**:
  - Low confidence scores (< 0.60) (`R-VAL-CONF`).
  - Assumed profile materials/finishes (`R-VAL-MAT`).
- **Approval Endpoints & Persistence**:
  - `POST /jobs/{id}/approve`: Validates draft; raises HTTP 409 (`approval_blocked`) with detailed issue list if invalid; freezes immutable `BomVersion` record in `bom_version` table when valid.
  - `GET /jobs/{id}/versions`: Lists all frozen versions for a job.
  - `GET /jobs/{id}/versions/{version}`: Retrieves frozen version payload.

### 1.6 Line Dependency Index & Partial Re-Run (`packages/rules/src/c2b_rules/dependency.py`, `docs/04 §12`)
- **User Line Edits (`apply_user_line_edit`)**:
  - Directly sets edited values with `source="user"`, confidence 1.0, and rule `R-USR-EDIT`.
  - Recalculates material mass, rolled-up parent quantities, MBOM, open items, and validation.
  - User edits are permanently protected against subsequent pipeline re-runs.
- **Question Answers (`apply_question_answer`)**:
  - Records user's answer, updates target line quantities, cascades through parent assemblies.
- **Suggestion Reviews (`apply_suggestion_review`)**:
  - Accepts suggestions into EBOM/MBOM or stores rejected keys to permanently suppress them.
