## 1. What Was Built

### 1.1 Domain Models (`packages/domain`)
- **CAD Hierarchy Models (`cad.py`)**:
  - `CadNode`: Tree node representation (`N-0001`...) with parent reference, kind (`assembly | part | reference`), instance count, 4x4 column-major transform matrix, color RGBA, AP242 user properties, and prototype shape linkage (`S-0001`...).
  - `Cyl` / `CylinderFeature`: Parametric cylinder descriptor (`radius_mm`, `length_mm`, `axis`, `is_inner`).
  - `ShapeFeatures`: Geometric descriptors per unique prototype shape: mass properties (`volume_mm3`, `area_mm2`), oriented bounding box (`obb_mm`), face-type histogram (`face_hist`), cylinder list with inner bore classification, rotational symmetry score (`rot_symmetry`), sheet metal constant thickness (`const_thickness_mm`), wall-thickness samples (`wall_sample_mm`), thin-plate boolean (`thin_plate`), helix evidence, topological closure (`closed`), and canonical SHA-256 signature hash (`signature`).
  - `CadNotice`: Quality notices with severity levels (`info`, `warning`, `error`) and standardized codes (`empty_shape`, `open_shell`, `unit_mismatch`, `duplicate_instance`, `large_file`, `broken_file`).
  - `CadExtractResult`: Structured container for nodes, prototype shapes, notices, leaf count, GLB relative path, and sampling flag.
  - `JobUpdate`: Schema for `PATCH /jobs/{job_id}` supporting `consent_native_conversion`.

### 1.2 Database Storage & Migration (`packages/jobs`)
- **Migration `003_cad_extract.sql`**: Table `cad_extract` storing extracted CAD JSON per job upload with leaf counts and timestamp index.
- **Repository Methods (`repo.py`)**:
  - `save_cad_extract(pool, job_id, upload_id, data, leaf_count)`: Upserts extraction payload on conflict.
  - `get_cad_extract(pool, job_id)`: Fetches most recent CAD extract for a job.
  - `set_consent_native_conversion(pool, job_id, consent)`: Updates native conversion consent flag.
  - `create_job(...)`: Updated to accept initial `consent_native_conversion` flag.

### 1.3 Sandboxed CAD Worker Engine (`apps/cad-worker`)
- **Geometric Feature Extraction (`c2b_cad_worker.features`)**:
  - Mass properties computed with `BRepGProp.VolumeProperties_s` and `BRepGProp.SurfaceProperties_s`.
  - Oriented bounding box (OBB) computed with `BRepBndLib.AddOBB_s` with AABB fallback.
  - Face-type exploration classifying planar, cylindrical, conical, spherical, toroidal, and B-spline faces into area fractions.
  - Accurate inner/outer cylinder bore classification using `BRepClass3d_SolidClassifier` evaluating inward/outward normal perturbations.
  - Rotational symmetry scoring quantifying the surface area fraction sharing a common revolution axis.
  - Sheet metal constant thickness detection identifying paired parallel opposing planar faces.
  - Thin-plate detection flagging components with smallest OBB dimension $\le 3\text{ mm}$ and dominant planar faces.
  - Solid and shell topological closure evaluation with `BRepCheck_Analyzer`.
- **STEP Extraction & GLB Generation (`c2b_cad_worker.extract`)**:
  - XCAF tree reader with `STEPCAFControl_Reader` (colors, layers, names, AP242 props).
  - Traversal mapping assembly hierarchy into consolidated `CadNode` trees (`N-0001`...) with instance counts.
  - Automated tessellation with `BRepMesh_IncrementalMesh` (`linear_deflection = 0.05 mm`, `angular_deflection = 0.5 rad`).
  - Direct binary GLB export via `RWGltf_CafWriter` with coordinate scale factor 0.001 (mm $\to$ m) and GLTF node names set to `CadNode.id`.
  - Quality validations flagging empty shapes, open shells, unit scale mismatches (>10 m or <0.1 mm), and duplicate overlapping instances.
- **Subprocess Runner (`server.py`)**:
  - Integrated `c2b_cad_worker.extract` with automatic job output directory routing (`data/jobs/<id>/out/`).

### 1.4 Pipeline Worker Integration (`apps/worker`)
- **Task Runner (`tasks.py`)**:
  - Updated `cad_extract` task to process real `CadExtractResult`, store records into `cad_extract` table via `repo.save_cad_extract`, emit quality notices as job events, record `cad_extracted` event with node/shape/leaf counts, and advance status to `building`.

### 1.5 API & Model Serving (`apps/api`)
- **Routes (`jobs.py`)**:
  - `GET /jobs/{job_id}/model.glb`: Serves binary GLB 3D model with `model/gltf-binary` content type and 404 ProblemDetail if not ready.
  - `PATCH /jobs/{job_id}`: Updates `consent_native_conversion` flag.
  - `create_job` and `_job_out`: Propagates `consent_native_conversion` to and from clients.

### 1.6 Native CAD Adapter (`apps/native-adapter`)
- **Interface & Stub (`c2b_native_adapter`)**:
  - Protocol `NativeAdapter` with method `convert(file_path: Path) -> ConvertedModel`.
  - `StubNativeAdapter` returning status `"not_configured"` with guidance to export STEP AP242 directly from authoring CAD packages.

## 4. Corrupt / Broken STEP Resilience

A deliberately truncated and corrupt STEP file (`ISO-10303-21; ... unexpected EOF`) was executed against the extractor:
- **Exit Code**: 0 (no unhandled exception or process abort).
- **Extraction Status**: `"error"`.
- **Emitted Notice**:
  `Notice [broken_file]: The CAD reader could not open '<file>.step' (status: fail). The file may be corrupt or not a valid STEP AP203/AP214/AP242 file.`
- **Result**: Graceful failure reported cleanly to the client and queue runner.
