## 1. What Was Built

### 1.1 Knowledge Base (`library/`)
- **Versioned Library (`library/VERSION.yaml`)**: Version `2026.11.0`, checksum `f23c35dede7b` at P1; the library content changed during P3–P6 without a version bump (checksum is now different, see P0-P6-review.md).
- **Taxonomy (`library/taxonomy.yaml`)**: 397 resolved classes across 16 primary domains (fasteners, bearings, transmission, seals, springs, sheet metal, machined, moulded, cast, extrusions, wood, glass, electrical, fluid, packaging, consumables). Each class defines its noun, modifiers, default UoM, make/buy default, `usually_modelled` flag, `buy_as_assembly` flag, `description_template`, standard families, profile keys, and optional UNSPSC codes.
- **Materials (`library/materials.yaml`)**: 66 materials across 15 families (`carbon_steel`, `alloy_steel`, `stainless_steel`, `aluminium`, `copper_alloy`, `zinc`, `magnesium`, `titanium`, `thermoplastic`, `thermoset`, `elastomer`, `wood`, `glass`, `paper`, `other`). Each includes density, international designations (EN, IS, ASTM/SAE, JIS, ISO), uses, finishes, explicit `density_source`, and `verify: true`.
- **Standard-Part Tables (`library/standards/`)**: 16 parametric standard tables (301 nominal rows total) covering metric fasteners M2–M24, dowels, bearings, and O-rings. Every table records its source and retains `verify: true`.
- **Synonyms & Patterns (`library/synonyms/`)**: 1600 tokens across English (`en.yaml`), German starter set (`de.yaml`), and `patterns.yaml` (regex patterns and supplier prefixes).
- **Configuration & Rules**: `library/headers.yaml` (multilingual header synonyms and scoring weights), `library/units.yaml` (unit aliases and SI base units), `library/profiles/default.yaml` (numbering, description case, find numbers, export schema), `library/confidence.yaml` (source base confidences, weights, thresholds), `library/rules/` (33 initial classification, structure, gap, MBOM, and validation rules), and `library/archetypes/` (skeletons for `ceiling_fan` and `power_bank`).

### 1.2 Library Engine (`packages/library`)
- **Schemas (`schemas.py`)**: Strict Pydantic v2 models for all YAML files under `library/`.
- **Validation Engine (`checks.py`)**: Implementation of all checks in `docs/06 §8`:
  - `L-TAX-001..006`: Template field validation, default UoM validity, uniqueness, parent hierarchy checks.
  - `L-MAT-001..003`: Material uniqueness, profile references, density bounds.
  - `L-STD-001..010`: Standard key uniqueness, dimension monotonicity, positive dimensions, strictly ascending lengths.
  - `L-SYN-001..005`: Class existence, pattern regex validation, cross-domain synonym collision detection.
  - `L-RUL-001..004`: Rule ID format, stage validity, note completeness, class reference validity.
  - `L-VER-001`: Summary audit of `verify: true` flags across tables and materials.
- **Database Loader (`db.py` & `loader.py`)**: Single-transaction idempotent loader into Postgres tables (`library_version`, `library_class`, `library_material`, `library_standard`, `library_synonym`, `library_rule`, `library_blob`) keyed by version string.
- **CLI (`cli.py`)**: `c2b-library validate`, `c2b-library load`, and `c2b-library search`.
- **Offline Search (`search.py`)**: Fast YAML search scoring across classes, materials, standards, and synonyms without requiring a live database.

### 1.3 Synthetic Fixture Generator (`tools/fixtures`)
- **CadQuery & OpenCascade Fixture Builder (`c2b_fixtures`)**: Generates exact parametric STEP assemblies using OpenCascade XCAF (`STEPCAFControl_Writer`):
  - Preserves hierarchical prototype shapes and instance transforms (not flattened).
  - Injects fixed timestamps (`2026-11-20T00:00:00`) for reproducible, byte-identical output across runs.
- **CLI (`c2b-fixtures build`)**: Generates inputs and expected outputs for all golden test cases.

### 1.4 Golden Test Cases (`golden/`)
- **B1 Fastener Zoo (`B1_fastener_zoo/`)**: Synthetic STEP with 12 distinct parts (33 instances; M4 screws, nuts and washers ×8) covering ISO 4762 cap screws, ISO 4032 nuts, ISO 7089 washers, ISO 2338 dowels, 6201 ball bearing, and metric O-ring. Named `Part1..PartN`.
- **B2 Bracket Assembly (`B2_bracket/`)**: Sheet metal bracket (2 bends), turned shaft, moulded cover, machined block, and a 2x instanced `FASTENERS_GRP` phantom assembly.
- **B3 Fan (`B3_fan/`)**: 13-solid synthetic fan STEP (3 blades modelled; details text specifies 4 blades), details text, placeholder photo, provisional owner model (`fan_real.step`), questions, and suggestions.
- **B4 Power Bank BoM (`B4_power_bank/`)**: Messy supplier Excel workbook (`supplier_bom.xlsx`) with title block, mixed German/English headers, grouped refdes, and `pcs`/`nos` units.
- **B5 CAD + Incomplete BoM (`B5_cad_plus_bom/`)**: B2 STEP + user workbook with 3 missing CAD parts and 1 quantity mismatch.
- **B6 Unknown Product (`B6_unknown/`)**: STEP with parts `Body1..BodyN` of uncatalogued product type, with LLM expectations recorded.
